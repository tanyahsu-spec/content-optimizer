# SEO 檢查清單(傳統搜尋引擎排名因子)

用於評估內容是否符合 Google 等傳統搜尋引擎的排名要求。這份清單關注「機器與演算法怎麼讀這篇內容」——關鍵字、結構標記、連結、速度等可量化的訊號。

---

## 1. 關鍵字密度與位置

檢查目標關鍵字(以及 1-2 個相關同義詞/長尾詞)是否出現在以下高權重位置:

| 位置 | 要求 |
|---|---|
| Title / H1 | 關鍵字應出現一次,越靠前越好 |
| 前 100 字(第一段) | 至少出現一次,自然融入,不生硬 |
| URL slug | 應包含關鍵字,不含贅字(如 the、a、and) |
| 至少一個 H2 | 至少一個子標題包含關鍵字或其變化形 |
| 內文整體密度 | 落在約 0.5%-2.5% 之間;超過 3% 視為關鍵字堆砌(keyword stuffing),會被扣分 |

**常見問題**:關鍵字只出現在第一段就再也沒出現、URL 是流水號或無意義字串、標題為了吸睛完全沒放關鍵字。

## 2. Meta Title / Meta Description

Google 在 SERP 上是依**像素寬度**截斷 title/description,不是依字元數;以下數字是以英文/半形字元為基準換算的**經驗值**,實際適用哪個範圍取決於內容語言:

- **英文/以半形字元為主的內容**:title 50-60 個字元,description 150-160 個字元。
- **純中文/CJK 全形字元為主的內容**:全形字元的顯示寬度約為半形字元的兩倍,對應範圍要減半——**title 約 25-35 個全形字元,description 約 70-100 個全形字元**。若中文內容硬套用 150-160 字元的英文標準,寫出來的 description 在 SERP 上一樣會被截斷,等於沒解決問題。
- 兩者都應包含主要關鍵字(越前面越好)、明確的價值主張或行動呼籲(CTA),讓使用者在 SERP 上想點擊。
- 兩者都不應是內文的機械截斷,應是專門撰寫、獨立成立的句子。

檢查時請先判斷內容主要語言(中文/英文/混合),套用對應的字元範圍,實際計算字元數並回報,不要用「差不多」帶過,也不要不分語言一律套用同一組數字。

## 3. 標題階層(H1-H3)

- 全頁應**只有一個 H1**,且等於或高度相關於頁面主題。
- H2 用於劃分主要段落,順序應反映內容的邏輯結構(而非隨意排列)。
- H3 從屬於對應的 H2 之下,不可跳級(例如 H1 底下直接接 H3)。
- 每個標題本身應該有意義,即使脫離內文單獨閱讀也能大致理解該段在講什麼(這點也會影響 AEO/GEO 分數,見對應清單)。

## 4. 內部連結與外部連結策略

- **內部連結**:內文中應有 2-5 個指向站內相關文章/頁面的連結,錨點文字(anchor text)需具描述性(避免「點此」「這裡」)。
- **外部連結**:適度連結到高權威、非競爭對手的來源(如官方文件、研究報告、統計數據出處),有助於建立內容可信度。
- 檢查是否有斷鏈或指向不相關頁面的連結。

## 5. 頁面速度相關(圖片壓縮、alt text)

- 所有圖片是否有描述性的 `alt` 文字(非空白、非檔名如 `IMG_1234.jpg`),且盡量自然帶入關鍵字(不強求每張都塞關鍵字)。
- 圖片檔案是否經過壓縮/使用現代格式(WebP/AVIF 優於未壓縮 PNG/JPG)。
- 是否有明顯會拖慢載入速度的元素(未設定尺寸導致版面跳動、過多未延遲載入的圖片)。
- 若無法直接檢測實際載入速度,至少檢查上述靜態線索並提醒使用者用 PageSpeed Insights 等工具實測。

## 6. Backlink 策略建議

內文本身通常無法「檢查」backlink(那是外部訊號),但應根據內容主題給出具體建議,例如:
- 內容是否具備「值得被連結」的特質(原創數據、獨家觀點、實用工具/範本、深度指南)——如果只是重述常識,很難吸引自然反向連結。
- 建議可主動爭取連結的管道(產業目錄、來賓投稿、資源頁面收錄、與相關領域網站互換連結)。
- 是否適合製作成「連結誘餌」內容(如原創調查報告、免費工具)。

## 7. URL 結構

- 簡短、可讀、使用連字號分隔單字(不用底線或空格編碼)。
- 反映網站的資訊架構(如 `/blog/category/article-slug`),避免無意義的參數或過深的層級。
- 不含日期(除非是新聞類網站,日期有助於時效性判斷),避免文章更新後 URL 顯得過時。

---

## 評分方式

總分 100 分,以下為建議配分(可依內容類型微調並在報告中註明):

| 項目 | 配分 |
|---|---|
| 關鍵字密度與位置 | 20 |
| Meta title / description | 15 |
| 標題階層 | 15 |
| 內部/外部連結 | 15 |
| 頁面速度相關(圖片/alt) | 15 |
| Backlink 策略可行性 | 10 |
| URL 結構 | 10 |

每項先判定「符合(滿分)/ 部分符合(半分)/ 不符合(0 分)」,再加總。若某項因資訊不足無法判斷(例如看不到實際頁面速度),在報告中註明「無法評估」並從總分母中扣除該項配分,而非直接給 0 分。
